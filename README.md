Install Python 3.2. Keep all project files in the same folder.3. Open a terminal in the project folder.4. Run:```bashpython main.py```If required, use:```bashpython3 main.py```The results will be written to `output.txt`.## ## Sample Output```text13----------------16-----------------10----------------17----------------16```## ## Stack OperationsThe Stack class implements:* `push()`* `pop()`* `peek()`* `is\\\\\\\\\\\\\\\_empty()`The evaluator uses one stack for values and another for operators.## ## Assumptions and Limitations* Supported operators are +, -, \*, and /.* Parentheses must be properly matched.* Division by zero is not allowed.* Expressions should contain valid mathematical syntax.* Advanced operations such as powers, square roots, and trigonometric functions are not supported.
